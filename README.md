# Java Networking Server

## Project Overview
This project is a Java-based server application developed to demonstrate client-server communication using Java socket programming.

The server listens for incoming client connections and handles communication between applications.

## Technologies Used
- Java
- Java Socket Programming
- Maven
- Apache NetBeans

## Key Concepts
- Server-side socket programming
- Client-server architecture
- Input and output streams
- Handling client connections
- Sending and receiving data

## Project Structure
The project uses Maven to organise its source code and manage its configuration.

## Learning Outcomes
This project helped develop an understanding of how servers accept client connections and communicate with client applications using Java sockets.
